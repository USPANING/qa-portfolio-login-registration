- QA Portfolio: Login & Registration Testing (ParaBank)
  
-- Project Goal
 * The Goal of this project is demonstrate the foundational Manual skills by perfoming functional, UI/UX, and negative testing on the authentication and user registration modules of public demo application

-- Application Under Test (AUT)
 * Application Name: ParaBank (Parasoft Deomo Site)
 * URL: [https://parabank.parasoft.com/](https://parabank.parasoft.com/)

-- Scope 
 * User Registration module (`/register.htm`)
 * User Login and Logout module (`/index.htm`, `/overview.htm`)
 * Basic form validation and error handling for empty/invalid inputs

-- Environment and tools
 * Browser: Google Chrome (version: 152.0.7977.84)
 * DevTools: Console, Network tab (for observing HTTP requests)
 * Documention and Management: MarkDown, Git/GitHub

-- Testing Types Applied
 * Functional Testing
 * Posiive & Negative Testing
 * UI/Usability Testing
 * Boundary Value Analysis (basic form constrains)
